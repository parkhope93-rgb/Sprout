# Sprout Mindmap Prototype

## Project structure

```text
sprout_mindmap/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
├── assets/
│   └── icons/
└── README.md
```

## Run locally

Open `index.html` in a browser, or use the VS Code Live Server extension.

## Notes

- `index.html`: page structure
- `css/style.css`: visual styles
- `js/main.js`: interactive behavior and sample mind-map data
- Data is saved in the browser's localStorage.
- The Google Fonts import requires an internet connection; fallback fonts are configured.
